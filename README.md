# Gratitude Card

A tiny, no-signup web page for making a Thanksgiving gratitude card.

1. Pick a prompt
2. Write a name and a message
3. Pick a style (and add a photo if you like)
4. **Send as a link** — the receiver taps the heart seal and the envelope opens — or **save the image**.

Nothing is uploaded. The card's text lives only in the link's `#hash`, which browsers never send to a server.

Everything is one file: `index.html`. Fork it, change the prompts or styles, and make it yours.
